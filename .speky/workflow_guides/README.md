# SPEKY Workflows

This folder contains detailed workflow documentation for spec-driven development. These workflows are **reusable across projects** - just set the project variables.

## Project Variables (Required)

Before using any workflow, set these variables:

```bash
$PROJECT_ROOT = '/path/to/your/project'      # REQUIRED: Absolute project path
$CURRENT_PLAN = '$PROJECT_ROOT/plan.md'      # REQUIRED: Implementation plan path
$FLUTTER_REF_PATH = ''                       # OPTIONAL: Flutter reference project
$HIFI_DESIGNS_PATH = ''                      # OPTIONAL: HiFi designs folder
```

## Available Workflows

| Workflow | Description | When to Use |
|----------|-------------|-------------|
| [spec-generation-workflow.md](./spec-generation-workflow.md) | Generate comprehensive SPEKY specs from implementation plans | Starting a new feature/phase |
| [implementation-workflow.md](./implementation-workflow.md) | Implement specs using IMPLEMENTATION-GUIDE | After `speky implement <id>` |
| [review-integration-workflow.md](./review-integration-workflow.md) | How review documents integrate with specs | Understanding the review system |

## Quick Start

### Creating New Specs
```bash
# 1. Set project variables
# 2. Have an implementation plan ready
# 3. Use the spec generation prompt (see spec-generation-workflow.md)
# 4. AI generates all files automatically
```

### Implementing Specs (Standard Mode)
```bash
# 1. Run SPEKY command
speky implement 017

# 2. Prompt AI with implementation guide
@$PROJECT_ROOT/.speky/specs/017-browser-foundation-webcontents-service/IMPLEMENTATION-GUIDE.md

# 3. Follow the guide phases
# 4. Complete with
speky complete 017
```

### Implementing Specs (TDD Mode)
```bash
# 1. Run SPEKY command with --tdd flag
speky implement 017 --tdd

# 2. Check for generated test task
ls $PROJECT_ROOT/.speky/testing/tasks/T017-tdd/test_task.md

# 3. Prompt AI with BOTH files (test task + implementation guide)
@$PROJECT_ROOT/.speky/testing/tasks/T017-tdd/test_task.md
@$PROJECT_ROOT/.speky/specs/017-browser-foundation-webcontents-service/IMPLEMENTATION-GUIDE.md

# 4. Follow TDD: Write tests FIRST, then implement
# 5. Complete with
speky complete 017
```

## TDD Mode Quick Reference

| Command | Result |
|---------|--------|
| `speky implement 017` | Standard mode - no test task |
| `speky implement 017 --tdd` | TDD mode - generates `T017-tdd/test_task.md` |

**TDD Task Path Pattern:**
```
$PROJECT_ROOT/.speky/testing/tasks/T<SPEC_ID>-tdd/test_task.md
```
